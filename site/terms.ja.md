# ClearFlow（清流）利用規約

適用開始日：2026年10月24日

本規約は、OhMyAI（以下「当社」）が提供する有料サービス、ClearFlow メンバーシップに適用されます。ClearFlow のブラウザー拡張機能は無料で、MIT License のもとでオープンソースとして提供されています。ご自身の API キーを使う場合、メンバーシップは不要です。その場合は MIT License と[プライバシーポリシー](https://clearflow.ohmyai.app/ja/privacy/)のみが適用されます。ClearFlow メンバーシップを購入または利用することで、本規約に同意したものとみなされます。お問い合わせ：developer@ohmyai.app

## 1. メンバーシップについて

ClearFlow メンバーシップでは、ご自身の API キーを用意しなくても、当社のサーバーを通じて ClearFlow の AI 機能（返信の判定や、YouTube の字幕を含む翻訳機能の強化）を利用できます。ご自身の API キーを使う場合と機能は同じですが、返信内の画像は判定されません。

## 2. アカウント

- メールアドレスでログインします。そのメールを読める人はログインできるため、安全に管理してください。
- メンバーシップは1人で利用するものです。最大3台のデバイスでログインでき、アカウントページからデバイスを削除できます。
- お住まいの地域で契約を結べる年齢に達しているか、保護者の許可を得ている必要があります。
- 新規アカウントには、カード登録不要の7日間無料トライアルが1回あります。トライアルはメールアドレスごと、デバイスごとに1回までです。トライアル期間中は、1日の利用上限が低く設定されています。

## 3. プランと支払い

- **プラン：**月額プラン（$2.90／月）と年額プラン（$24／年）は自動更新されます。30日パス（$3.90）と1年パス（$39）は買い切りで、自動更新されません。現在の料金は[料金ページ](https://clearflow.ohmyai.app/ja/pricing/)で確認できます。料金は米ドルで、適用される税金を含みます。
- **決済処理者：**オンライン再販業者であり、販売者としての記録上の責任を負う Waffo（Waffo.com Limited）が決済を処理し、請求書と税金を取り扱います。購入には Waffo 独自の規約も適用されます。当社がお客様のカード情報を見ることはありません。
- **更新：**サブスクリプションは、解約するまで各請求期間の終了時に自動更新されます。プランの料金を変更した場合、新料金は新規のサブスクリプションに適用されます。既存のサブスクリプションの料金は変わりません。
- **更新時の決済失敗：**更新時の決済に失敗した場合、決済を再試行する間、最長3日間メンバーシップを利用できます。それでも決済できない場合、サブスクリプションは終了します。
- **パス：**メンバーシップの利用期間中にパスを購入した場合、現在の期間が終了してから新しいパスが始まります。更新予定のサブスクリプションがある間はパスを購入できません。先に解約するか、終了するまでお待ちください。

## 4. 解約

- アカウントページまたは Waffo の請求ページから、いつでもサブスクリプションを解約できます。支払い済みの期間が終了するまでは利用でき、その後は更新されません。期間終了前であれば、再開できます。
- 第5条に定める返金を除き、期間の一部について返金やクレジットの付与は行いません。

## 5. 返金

- アカウントでの初回購入から7日以内であれば、理由を問わず全額返金を受けられます。アカウントページまたはメールから申請してください。
- 返金すると、その支払い対象のメンバーシップはすぐに終了します。パスの場合、それ以降に購入したパスの開始時期が前倒しされます。
- その他の返金は、法律で義務付けられている場合を除き、当社の判断で行います。
- 当社に連絡せず銀行に請求への異議を申し立てた場合、異議が解決するまでアカウントを一時停止することがあります。

## 6. 利用枠と適正な利用

- 各メンバーシップには、日常的なヘビーユースを想定した月間利用枠と1日の上限があります。今月の利用枠の使用量は、拡張機能で確認できます。上限に達すると、翌日または翌月まで AI 機能が一時停止します。ローカルルールは引き続き機能します。
- ClearFlow の拡張機能とウェブサイト以外の方法でメンバーシップを利用すること（たとえば、当社の API を直接呼び出すこと）、アカウントの共有、アクセス権の再販売、自動リクエストの送信、利用上限やトライアル1回のルールの回避は禁止されています。違反したアカウントは一時停止することがあります。

## 7. AI の結果には誤りが含まれる場合があります

AI モデルが返信を判定し、テキストを翻訳するため、誤りが生じることがあります。通常の返信が不適切に修正されたり、スパムを見逃したり、翻訳が不正確になったりする可能性があります。ClearFlow が修正した内容は確認でき、誤りを報告することもできます。誤りが重大な影響を及ぼす場面では、ClearFlow に頼らないでください。

## 8. 他のサイトとサービス

- ClearFlow は X、YouTube、Reddit、小紅書（RedNote）、Hacker News で動作しますが、これらのサービスとは提携していません。各サイトは頻繁に変更されるため、変更によって機能が使えなくなり、拡張機能の更新が必要になる場合があります。
- メンバーシップを提供するため、プライバシーポリシーに記載のとおり、コンテンツをサービス提供者（OpenRouter、TypeSafe、翻訳モデル）に送信します。

## 9. 変更

- 機能を追加、変更、削除することがあります。
- 有料メンバーに影響する本規約の変更を適用する場合、少なくとも14日前にメールでお知らせします。
- ClearFlow メンバーシップの提供を終了する場合、少なくとも30日前にお知らせし、年額プランまたはパスの未使用分を返金します。

## 10. アカウントの一時停止と削除

- アカウントページから、いつでもアカウントを削除できます。更新予定のサブスクリプションがある場合は、先に解約されます。
- 本規約に違反したアカウントは、一時停止または閉鎖することがあります。その他の理由でアカウントを閉鎖する場合、支払い済み金額の未使用分を返金します。

## 11. 保証と責任

法律で認められる範囲で、ClearFlow は「現状有姿」で提供され、保証はありません。メンバーシップに関する請求について、当社が負う責任の総額は、請求が発生する前の12か月間にお客様が当社に支払った金額を上限とします。本規約によって、放棄できない消費者法上の権利が制限されることはありません。
