# ClearFlow 개인정보 처리방침

시행일: 2026년 10월 26일

ClearFlow는 X, Reddit, YouTube, Xiaohongshu (RedNote), Hacker News의 댓글을 정리하고 게시물을 번역하는 브라우저 확장 프로그램입니다. OhMyAI가 제공합니다. 이 방침에서는 확장 프로그램이 어떤 정보를 읽고, 누구에게 전송하며, 기기에 무엇을 저장하는지 설명합니다.

**간단히 설명하면:** ClearFlow는 사용자가 보고 있는 댓글과 게시물을 사용자가 직접 입력한 API 키로 OpenRouter에 전송합니다. OpenRouter는 이를 TypeSafe의 Jev 모델에 전달해 판단을 받고, 번역 모델에 전달해 번역합니다. 선택 사항으로 TypeSafe 키를 추가하면 판단 요청은 TypeSafe로 직접 전송됩니다. 이 방식으로 사용할 경우 개발자인 저희에게 전송되는 정보는 없습니다. 대신 유료 선택 사항인 ClearFlow 멤버십을 이용하면(아래 관련 항목 참고) 같은 콘텐츠가 저희 서버를 거치며, 서버에는 해당 항목에 명시된 정보만 보관됩니다. 사용 통계를 업로드하거나 브라우징 동작을 추적하지 않으며, 원격 코드를 실행하지 않습니다. 그 밖의 저장 데이터는 브라우저에 보관됩니다.

## 실행되는 사이트

확장 프로그램의 스크립트는 다음 사이트에서만 실행됩니다: `x.com`, `twitter.com`, `www.reddit.com`, `www.youtube.com`, `www.xiaohongshu.com`, `www.rednote.com`, `news.ycombinator.com`. 브라우징 기록이나 다른 웹사이트는 읽지 않습니다. 해당 사이트에서는 사용자의 게시물을 판단하지 않도록 사용자 이름만 로컬에서 읽으며, 이 정보는 어디에도 전송하지 않습니다.

## 전송되는 정보와 수신자

### TypeSafe의 Jev 모델 — 댓글 판단

댓글 정리(스팸, 괴롭힘, 성적 콘텐츠, “좋아요”나 “+1” 같은 답글)에 사용되며, X의 자체 번역과 YouTube의 자동 번역 자막 품질 판단에도 사용됩니다. 기본적으로 요청은 사용자의 OpenRouter 키를 이용해 OpenRouter(`openrouter.ai`)를 거쳐 TypeSafe로 전달됩니다. 설정 → 고급에서 TypeSafe 키를 입력하면(선택 사항) 요청이 TypeSafe(`api.typesafe.ai`)로 직접 전송됩니다. 두 키를 모두 입력하지 않으면 아무것도 전송되지 않습니다.

- 로컬 규칙으로 판단할 수 없는 페이지 내 각 댓글에 대해 댓글 내용(최대 600자), 댓글 작성자의 표시 이름과 사용자 이름, 댓글이 달린 게시물의 내용(최대 400자), 게시물 작성자의 이름과 사용자 이름을 전송합니다. 요청당 댓글은 최대 10개입니다.
- X의 프로필 및 검색 페이지와 Reddit의 목록 페이지에서는 댓글 대신 목록의 게시물을 전송하며, 게시물 내용 대신 고정된 한 줄 설명을 보냅니다.
- X가 자동 번역한 게시물에서는 X의 번역이 충분히 좋은지 판단하기 위해 원문과 X(Grok)의 번역문을 전송합니다. ClearFlow가 다시 번역한 내용은 전송하지 않습니다.
- TypeSafe 키를 입력하고 “답글 이미지 확인”을 켠 경우에만(기본값은 꺼짐) 해당 댓글에 첨부된 이미지를 축소해 텍스트와 함께 TypeSafe로 직접 전송합니다. OpenRouter는 이미지를 전달하지 않으므로 TypeSafe 키가 없으면 이미지를 전송하지 않습니다. 이 기능을 위해 확장 프로그램은 `pbs.twimg.com`, `i.redd.it`, `preview.redd.it`, `*.xhscdn.com`에서 이미지를 읽을 권한을 요청하며, 옵션을 끄면 권한을 반납합니다.
- 해당 사이트에서 직접 스팸으로 표시한 경우에만(“이 답글 숨기기” 또는 알림 표시줄의 깔때기 아이콘) 최근에 표시한 답글 10개(최대 240자의 내용과 계정)를 예시로 댓글과 함께 전송합니다. 이를 통해 TypeSafe가 같은 유형의 스팸인지 판단할 수 있습니다. 표시 직후 해당 페이지에서 아직 정리되지 않은 댓글을 예시와 비교해 다시 확인합니다(요청당 최대 25개).
- YouTube에서는 YouTube 자동 번역 자막을 선택하고 “자동 번역 자막 개선”을 켠 경우에만, 그리고 대신 사용할 사람이 번역한 중국어 자막이 없는 경우에만 원본 자막과 YouTube 번역 자막의 첫 부분(최대 40줄)을 전송해 번역 품질을 판단합니다.
- 같은 맥락에서 같은 댓글에 대한 요청을 줄이기 위해 결과를 최대 7일간 로컬에 캐시합니다. 캐시를 지우거나 항목을 삭제한 경우, 또는 새 판단이 필요한 경우 댓글을 다시 전송할 수 있습니다.

### OpenRouter(`openrouter.ai`) — 번역 및 기본 판단

번역 요청은 OpenRouter 키를 입력했고 해당 사이트에서 번역 기능을 켠 경우에만 전송됩니다. TypeSafe 키가 없으면 위에 설명한 판단 요청도 OpenRouter를 거칩니다.

- 번역이 필요한 게시물과 댓글의 텍스트(X의 번역보다 더 나은 번역이 필요한 경우 포함)만 전송합니다. 작성자, 게시물 ID, 페이지의 다른 정보는 전송하지 않습니다.
- YouTube에서는 TypeSafe가 자동 번역 자막의 품질이 낮다고 판단한 경우에만(위 내용 참고), 현재 시청 중인 부분의 원본 자막을 약 40줄씩 전송해 다시 번역합니다. 번체 중국어 자막을 간체로 변환하는 작업은 사용자의 컴퓨터에서 이루어지며, 아무것도 전송되지 않습니다.
- OpenRouter는 설정에서 선택한 번역 모델(기본값은 OpenAI 모델, 대체 모델은 DeepSeek 모델)에 텍스트를 전달합니다. 각 제공업체에는 자체 데이터 정책이 있습니다.

### 그 밖의 수신자 없음

사용자가 자신의 키를 사용하면 ClearFlow는 위 두 서비스 외에는 OhMyAI나 다른 누구에게도 정보를 전송하지 않습니다(ClearFlow 멤버십은 아래 내용 참고). 사용량 및 비용 통계는 기기에 보관됩니다. 분석, 오류 보고, 광고 또는 추적 코드는 없습니다. 모든 코드는 확장 프로그램 패키지에 포함되어 있으며, 나중에 다운로드해 실행하는 코드는 없습니다.

설정에서 “연결 테스트”를 누르면 테스트할 서비스로 짧은 고정 예시 텍스트가 전송됩니다.

## 기기에 저장되는 정보

다음 정보는 브라우저의 확장 프로그램 저장소(`chrome.storage.local` 및 IndexedDB)에 저장됩니다. API 키는 해당 서비스에 요청을 보내는 데 사용되며, 표시한 스팸은 위 설명처럼 예시로 TypeSafe에 전송될 수 있습니다. 그 밖의 저장 데이터는 업로드되지 않습니다.

- 설정과 API 키(OpenRouter 키 및 추가한 경우 TypeSafe 키). 키는 이 브라우저의 확장 프로그램 전용 데이터베이스에 저장되므로, 방문하는 웹사이트와 해당 웹사이트에서 실행되는 확장 프로그램 스크립트는 읽을 수 없습니다. 확장 프로그램의 백그라운드 워커만 키를 사용합니다. 키는 암호화되지 않습니다.
- 일일 집계 정보(정리하거나 번역한 항목 수, 예상 비용).
- 수정 사항(“스팸 아님”, “이 답글 숨기기”)과 표시한 스팸 및 댓글 내용(최대 300자, 최근 수정 사항 3,000개, 표시한 답글 500개).
- TypeSafe 결과 캐시(지문과 점수만 저장하고 텍스트는 저장하지 않으며, 댓글 판단 후 7일이 지나면 삭제)와 번역 캐시(번역된 텍스트를 저장하며, 30일간 사용되지 않으면 삭제). 각 캐시의 기본 최대 용량은 50 MB이며, 용량이 가득 차면 오래된 항목부터 삭제됩니다.

X와 YouTube에서는 작은 스크립트 두 개(`pagedata.js`, `ytdata.js`)가 페이지 안에서 실행되어, 페이지가 이미 받은 해당 사이트의 API 응답을 읽습니다. 이를 통해 게시물의 원문(번역되지 않은 텍스트)과 댓글 작성자를 확인합니다. 읽기만 하며 요청을 보내거나 사이트가 받는 정보를 변경하지 않습니다.

## 사용자가 선택할 수 있는 사항

- 팝업이나 설정에서 특정 사이트의 ClearFlow를 끄거나 정리와 번역 기능을 각각 끌 수 있습니다.
- 설정 → 데이터 및 개인정보에서 데이터를 내보내고(설정, 통계, 수정 사항, 표시한 스팸), 캐시를 지우거나 수정 사항을 포함한 통계와 기록을 삭제할 수 있습니다. 표시한 스팸은 설정에서 확인할 수 있으며 항목별 또는 전체 삭제가 가능합니다.
- 확장 프로그램을 제거하면 저장된 정보가 모두 삭제됩니다.
- TypeSafe 또는 OpenRouter에서 언제든지 API 키를 취소하거나 새 키로 바꿀 수 있습니다.

## ClearFlow 멤버십(선택 사항, 유료)

ClearFlow 멤버십을 이용하면 직접 API 키를 사용하는 대신 이메일로 로그인해 ClearFlow의 AI 기능을 저희 서버를 통해 이용할 수 있습니다. 멤버십에는 [서비스 약관](https://clearflow.ohmyai.app/ko/terms/)이 적용됩니다. 멤버십을 이용하는 경우 이 방침의 나머지 내용에 더해 다음 사항이 적용됩니다.

### 콘텐츠가 전송되는 곳

확장 프로그램은 “전송되는 정보와 수신자” 항목에 설명된 것과 동일한 콘텐츠를 OpenRouter로 직접 보내는 대신 저희 서버 `api.clearflow.ohmyai.app`(Cloudflare에서 운영)로 전송합니다. 저희 서버는 같은 방식으로 OpenRouter와 TypeSafe에 전달한 뒤 결과를 돌려줍니다. 멤버십 이용 중에는 이미지를 확인하지 않습니다.

### 저희 서버에 보관되는 정보

- **계정:** 이메일 주소, 시간대(일일 한도가 현지 자정에 초기화되도록 하기 위함), 무료 체험 시작일.
- **기기:** 확장 프로그램이 생성한 임의 ID, 기기 이름(브라우저 및 운영체제), 확장 프로그램 버전, 기기에서 로그인한 시점과 마지막으로 확인된 시점.
- **로그인:** 로그인 코드와 토큰은 해시 형태로만 저장하며, 만료된 항목은 매일 삭제합니다.
- **사용량:** 일별 사용 한도와 요청 횟수. 한도 관리 및 결제 관련 문의 대응을 위해 13개월간 보관합니다.
- **결제:** 결제 처리업체이자 판매 기록상 판매자인 Waffo로부터 받은 주문 및 결제 ID, 요금제, 금액과 통화, 날짜, 환불 상태. 카드 정보는 저희가 받지 않습니다. Waffo는 자체 개인정보 처리방침에 따라 결제 정보를 보관합니다.
- **공유 결과 캐시:** 같은 작업에 중복으로 비용이 들지 않도록 판단 결과는 7일, 번역 결과는 30일간 입력값의 해시를 기준으로 캐시합니다. 판단 결과는 점수만 저장하고, 번역 결과는 번역된 텍스트를 저장합니다. 캐시 항목은 계정과 연결되지 않습니다.
- **요청 지표:** 비용과 오류를 확인하기 위해 각 요청의 기능, 요금제, 비용, 캐시 적중 여부와 처리 시간 및 계정 ID를 기록합니다. 약 3개월간 보관합니다.

캐시를 제외하면 저희 서버는 처리하는 댓글, 게시물 또는 자막을 저장하지 않으며, 모델 학습에 사용하지 않습니다.

### 이메일

로그인 코드는 Cloudflare의 이메일 서비스를 통해 전송됩니다. 마케팅 이메일은 보내지 않습니다.

### 계정 삭제

계정 페이지에서 계정을 삭제할 수 있습니다. 삭제하면 이메일 주소, 기기, 로그인 세션 및 사용 기록이 삭제됩니다. 회계와 환불 처리를 위해 이메일 주소를 제외한 결제 기록과 무료 체험을 사용한 기기 ID는 보관합니다. 이를 통해 무료 체험을 다시 사용할 수 없도록 합니다.

### 서비스 제공업체

Cloudflare(호스팅, 데이터베이스 및 이메일), Waffo(결제), OpenRouter, TypeSafe 및 번역 모델 제공업체(콘텐츠 처리).

## 아동

ClearFlow는 아동을 대상으로 하지 않으며, 누구의 정보도 고의로 수집하지 않습니다.

## 변경 사항

이 방침이 변경되면 새 시행일과 함께 https://github.com/remember2015/clearflow/blob/main/PRIVACY.md 에 새 버전을 게시하고 변경 내역에 기록합니다.
