# ClearFlow 개인정보 처리방침

시행일: 2026년 10월 23일

ClearFlow는 X, Reddit, YouTube, 샤오홍슈(RedNote), Hacker News에서 댓글을 정리하고 게시물을 번역하는 브라우저 확장 프로그램입니다. OhMyAI가 배포합니다. 이 방침은 확장 프로그램이 어떤 정보를 읽고, 무엇을 누구에게 보내며, 기기에 무엇을 저장하는지 설명합니다.

**핵심 내용:** ClearFlow는 사용자가 입력한 API 키를 사용해 현재 보는 댓글과 게시물을 사용자가 선택하고 비용을 지불하는 서비스인 OpenRouter에 보냅니다. OpenRouter는 이를 TypeSafe의 Jev 모델(판별)과 번역 모델(번역)에 전달합니다. TypeSafe 키도 선택적으로 추가한 경우, 판별 요청은 대신 TypeSafe로 직접 전송됩니다. 개발자인 저희에게는 아무것도 보내지 않습니다. 사용 통계를 업로드하거나 탐색 활동을 추적하지 않으며, 원격 코드를 실행하지 않습니다. 그 밖에 저장되는 데이터는 브라우저에 남습니다.

## 작동하는 사이트

확장 프로그램의 스크립트는 `x.com`, `twitter.com`, `www.reddit.com`, `www.youtube.com`, `www.xiaohongshu.com`, `www.rednote.com`, `news.ycombinator.com`에서만 실행됩니다. 방문 기록이나 다른 웹사이트는 읽지 않습니다. 지원 사이트에서는 본인이 쓴 게시물을 판별 대상에서 제외하기 위해 사용자 이름만 기기에서 확인하며, 어디에도 보내지 않습니다.

## 전송하는 정보와 대상

### TypeSafe의 Jev 모델 — 댓글 판별

스팸, 욕설, 선정적인 내용, ‘좋아요’나 ‘+1’ 같은 답글을 걸러내고, X가 제공한 번역과 YouTube의 자동 번역 자막의 품질을 판단하는 데 사용합니다. 기본적으로 이러한 요청은 사용자의 OpenRouter 키를 사용해 OpenRouter(`openrouter.ai`)를 거치며, OpenRouter가 이를 TypeSafe에 전달합니다. TypeSafe 키(선택 사항, 설정 → 고급에서 입력)를 입력한 경우에는 대신 TypeSafe(`api.typesafe.ai`)로 직접 전송됩니다. 어느 키도 입력하지 않은 경우에는 아무것도 전송되지 않습니다.

- 기기 내 규칙으로 판단하기 어려운 각 댓글에 대해 댓글 본문(최대 600자), 댓글 작성자의 표시 이름과 계정명, 댓글이 달린 게시물의 본문(최대 400자), 게시물 작성자의 표시 이름과 계정명을 보냅니다. 요청 한 번에 최대 10개 댓글을 보냅니다.
- X의 프로필·검색 페이지와 Reddit의 목록 페이지에서는 댓글 대신 목록의 게시물을 보냅니다. 이때 게시물 본문에 해당하는 칸에는 한 줄짜리 고정 설명을 넣습니다.
- X가 자동 번역한 게시물은 X(Grok)의 번역이 충분한지 판단하기 위해 원문과 X의 번역문을 보냅니다. ClearFlow가 다시 번역한 결과는 보내지 않습니다.
- TypeSafe 키를 입력하고 ‘답글 이미지 검사’를 켠 경우에만(기본값은 꺼짐) 댓글에 첨부된 이미지를 축소해 텍스트와 함께 TypeSafe로 직접 보냅니다(OpenRouter는 이미지를 전달하지 않으므로 TypeSafe 키가 없으면 이미지는 전송되지 않습니다). 이를 위해 `pbs.twimg.com`, `i.redd.it`, `preview.redd.it`, `*.xhscdn.com`의 이미지를 읽을 권한을 요청하며, 이 기능을 끄면 권한을 해제합니다.
- 해당 사이트에서 직접 스팸을 표시한 경우에만(‘이 답글 숨기기’ 또는 알림 표시줄의 깔때기 아이콘), 그 사이트에서 최근 표시한 답글 최대 10개를 댓글과 함께 예시로 보냅니다. 각 예시에는 본문 최대 240자와 계정 정보가 들어갑니다. TypeSafe가 같은 종류의 스팸인지 판단하는 데 사용합니다. 답글을 표시한 직후에는 그 페이지에서 아직 정리되지 않은 댓글을 예시와 대조해 한 번 더 검사합니다(요청 한 번에 최대 25개).
- YouTube에서 자동 번역 자막을 선택하고 ‘자동 번역 자막 개선’을 켰으며 대신 쓸 수 있는 사람이 만든 중국어 자막이 없는 경우에만, 원어 자막의 앞부분(최대 40줄)과 YouTube의 번역문을 보내 번역 품질을 판단합니다.
- 같은 맥락의 동일 댓글에 대한 반복 요청을 줄이기 위해 판별 결과를 기기에 최대 7일간 캐시합니다. 캐시를 비우거나 항목이 삭제되거나 새로운 판단이 필요하면 댓글이 다시 전송될 수 있습니다.

### OpenRouter (`openrouter.ai`) — 번역 및 기본 판별

번역 요청은 OpenRouter 키를 입력하고 해당 사이트의 번역 기능을 켠 경우에만 전송합니다. TypeSafe 키가 없으면 OpenRouter는 위에서 설명한 판별 요청도 전달합니다.

- 번역이 필요한 게시물과 댓글의 본문을 보냅니다. X의 번역보다 나은 번역을 만드는 경우도 포함합니다. 작성자, 게시물 ID 또는 페이지의 다른 정보는 보내지 않습니다.
- 위에서 설명한 대로 TypeSafe가 YouTube의 자동 번역 자막 품질이 낮다고 판단한 경우에만, 현재 시청 중인 부분의 원어 자막을 한 번에 약 40줄씩 보내 다시 번역합니다. 번체 중국어 자막을 간체로 바꾸는 작업은 기기에서 이루어지며 아무것도 전송하지 않습니다.
- OpenRouter는 설정에서 선택한 번역 모델에 텍스트를 전달합니다. 기본값은 OpenAI 모델이며 DeepSeek 모델을 예비로 사용합니다. 각 제공업체에는 별도의 데이터 처리방침이 있습니다.

### 그 밖의 전송 대상은 없습니다

ClearFlow는 위 두 서비스 외에 OhMyAI를 포함한 누구에게도 아무것도 보내지 않습니다. 사용량과 비용 통계는 기기에만 저장됩니다. 분석 정보나 오류 보고서를 전송하지 않으며 광고 또는 추적 코드도 없습니다. 모든 코드는 확장 프로그램 패키지에 포함되어 있으며 나중에 코드를 내려받아 실행하지 않습니다.

설정에서 ‘연결 테스트’를 누르면 짧은 고정 예시 문장이 테스트하는 서비스로 전송됩니다.

## 기기에 저장하는 정보

다음 데이터는 브라우저의 확장 프로그램 저장소(`chrome.storage.local` 및 IndexedDB)에 저장됩니다. API 키는 각 서비스 요청을 인증하는 데 사용하며, 직접 표시한 스팸은 위에서 설명한 대로 TypeSafe에 판별 예시로 보낼 수 있습니다. 그 밖의 저장 데이터는 업로드하지 않습니다.

- 설정과 API 키(OpenRouter 키 및 추가한 경우 TypeSafe 키). 키는 이 브라우저의 확장 프로그램 전용 데이터베이스에 저장됩니다. 방문하는 웹사이트나 그 사이트에서 실행되는 확장 프로그램 스크립트는 키를 읽을 수 없고, 확장 프로그램의 백그라운드 워커만 사용합니다. 키는 암호화되지 않습니다.
- 일별 건수(정리하거나 번역한 항목 수, 예상 비용).
- 사용자의 판별 수정(‘스팸 아님’, ‘이 답글 숨기기’)과 직접 표시한 스팸 및 댓글 본문. 본문은 최대 300자이며, 최근 수정 기록 3,000개와 표시한 답글 500개를 보관합니다.
- TypeSafe 판별 결과 캐시(본문 없이 식별용 지문과 점수만 저장하며 판별 7일 후 삭제)와 번역 캐시(번역문을 저장하며 30일 동안 사용하지 않으면 삭제). 각 캐시의 기본 최대 용량은 50MB이며, 가득 차면 오래된 항목부터 삭제합니다.

X와 YouTube에서는 작은 스크립트 두 개(`pagedata.js`, `ytdata.js`)가 페이지 안에서 실행되어 페이지가 이미 받은 사이트의 API 응답을 읽습니다. 게시물의 번역 전 원문과 댓글 작성자를 확인하기 위해서입니다. 이 스크립트는 읽기만 하며 요청을 보내거나 사이트가 받는 내용을 바꾸지 않습니다.

## 사용자가 선택할 수 있는 사항

- 팝업이나 설정에서 사이트별로 ClearFlow 전체를 끄거나 댓글 정리와 번역을 각각 끌 수 있습니다.
- 설정 → 데이터 및 개인정보에서 설정, 통계, 판별 수정 기록과 직접 표시한 스팸을 내보내고, 캐시를 비우거나 수정 기록을 포함한 통계와 기록을 삭제할 수 있습니다. 직접 표시한 스팸은 설정의 목록에서 하나씩 또는 모두 삭제할 수 있습니다.
- 확장 프로그램을 제거하면 저장된 모든 데이터가 삭제됩니다.
- TypeSafe 또는 OpenRouter에서 언제든 API 키를 폐기하거나 교체할 수 있습니다.

## 아동

ClearFlow는 아동을 대상으로 하지 않으며 누구의 정보도 의도적으로 수집하지 않습니다.

## 변경 사항

이 방침이 변경되면 새로운 시행일과 함께 https://github.com/remember2015/clearflow/blob/main/PRIVACY.md 에 새 버전을 게시하고 변경 기록에 알립니다.
