# ClearFlow プライバシーポリシー

施行日：2026 年 10 月 23 日

ClearFlow は、X・Reddit・YouTube・小紅書（RedNote）・Hacker News のコメント欄を整理し、投稿を翻訳するブラウザ拡張機能です。OhMyAI が公開しています。このポリシーでは、拡張機能が読み取る情報、送信する情報と送信先、端末に保存する情報を説明します。

**概要：** ClearFlow は、閲覧中のコメントや投稿を、ご自身で契約・支払いを行う OpenRouter に、ご自身で入力した API キーを使って送ります。OpenRouter は、それらを判定用の TypeSafe の Jev モデルと、翻訳用モデルに渡します。任意の TypeSafe キーも追加した場合、判定リクエストは TypeSafe に直接送られます。開発者には何も送りません。利用統計の送信や閲覧行動の追跡は行わず、外部からコードをダウンロードして実行することもありません。その他の保存データはブラウザ内に留まります。

## 動作するサイト

拡張機能のスクリプトは、`x.com`、`twitter.com`、`www.reddit.com`、`www.youtube.com`、`www.xiaohongshu.com`、`www.rednote.com`、`news.ycombinator.com` でのみ動作します。閲覧履歴や、それ以外のサイトは読み取りません。対応サイトでは、ご自身の投稿を判定対象から外すために、ご自身のユーザー名を端末内で確認します。この情報は送信しません。

## 送信する情報と送信先

### TypeSafe の Jev モデル：コメントの判定

スパム、誹謗中傷、性的な内容、「nice」「+1」などの返信の判定と、X の翻訳品質および YouTube の自動翻訳字幕の品質の判定に使います。標準では、これらのリクエストは OpenRouter（`openrouter.ai`）に OpenRouter のキーを使って送信され、OpenRouter が TypeSafe に渡します。任意の TypeSafe キーを「設定 → 詳細設定」で入力した場合、代わりに TypeSafe（`api.typesafe.ai`）へ直接送信されます。どちらのキーも入力していない場合、何も送信されません。

- ローカルルールで判定できないコメントごとに、本文（最大 600 文字）、投稿者の表示名とユーザー名、返信先の投稿の本文（最大 400 文字）、その投稿者の表示名とユーザー名を送ります。1 回のリクエストにつき最大 10 件です。
- X のプロフィール・検索ページと Reddit の一覧ページでは、コメントの代わりに一覧の投稿を送ります。返信先の投稿本文にあたる欄には、固定の短い説明を入れます。
- X が自動翻訳した投稿では、X の翻訳が十分かどうかを判定するために、原文と X（Grok）の訳文を送ります。ClearFlow が再翻訳した訳文は送りません。
- TypeSafe キーを入力し、「返信の画像を確認する」設定をオンにした場合のみ（初期設定はオフ）、コメントに添付された画像を縮小し、文章と一緒に TypeSafe に直接送ります（OpenRouter は画像を引き渡さないため、TypeSafe キーがなければ画像は送信されません）。このために、`pbs.twimg.com`、`i.redd.it`、`preview.redd.it`、`*.xhscdn.com` の画像を読み取る権限を求めます。設定をオフにすると、この権限を解除します。
- そのサイトでスパムを手動でマークした場合のみ（返信の非表示操作や通知バーのフィルターアイコン）、直近の最大 10 件の本文（最大 240 文字）とアカウントを、判定するコメントと一緒に例として送ります。同じ種類のスパムかどうかを見分けるためです。マークした直後は、そのページでまだ非表示になっていないコメントを例と照らし合わせて再判定します（1 回につき最大 25 件）。
- YouTube で自動翻訳の字幕を選び、字幕の翻訳を改善する設定がオンで、代わりに使える、人の手で作成された中国語字幕がない場合のみ、原語の字幕の冒頭（最大 40 行）と YouTube の訳文を送り、翻訳品質を判定します。
- 判定結果は端末内に最大 7 日間保存し、同じ文脈の同じコメントについて、繰り返しのリクエストを減らします。キャッシュを消去した場合、保存された結果が削除された場合、再判定が必要な場合などには、再び送信されることがあります。

### OpenRouter（`openrouter.ai`）：翻訳と標準の判定

翻訳リクエストは、OpenRouter のキーを入力し、そのサイトで翻訳をオンにしている場合のみ送信します。TypeSafe キーがない場合、OpenRouter は上記の判定リクエストも中継します。

- 翻訳が必要な投稿やコメントの本文を送ります。X の訳文を改善するために再翻訳する場合も含みます。投稿者、投稿 ID、ページ内のその他の情報は送りません。
- TypeSafe が YouTube の自動翻訳字幕の品質を低いと判定した場合のみ（前述）、再翻訳のため、視聴中の部分の原語字幕を約 40 行ずつ送ります。繁体字中国語の字幕を簡体字に変換する処理は端末内で行い、何も送信しません。
- OpenRouter は、設定で選んだ翻訳モデルに文章を渡します。初期設定は OpenAI のモデルで、予備として DeepSeek のモデルを使います。各提供元には、それぞれのデータ取り扱い方針があります。

### その他の送信先

ClearFlow は、上記の 2 つのサービス以外には、OhMyAI を含め何も送りません。利用件数と費用の統計は端末内だけに保存されます。統計の送信、クラッシュレポート、広告、追跡のコードはありません。すべてのコードは拡張機能のパッケージに含まれ、あとからダウンロードして実行することはありません。

設定で接続テストを実行すると、固定の短いサンプル文を、テストするサービスに送ります。

## 端末に保存する情報

以下の情報は、ブラウザの拡張機能用ストレージ（`chrome.storage.local` と IndexedDB）に保存します。API キーは各サービスへのリクエストの認証に使い、マークしたスパムは上記のとおり TypeSafe に判定の例として送ることがあります。それ以外の保存データはアップロードしません。

- 設定と API キー（OpenRouter のキーと、追加した場合は TypeSafe のキー）。キーは、このブラウザ内の拡張機能専用データベースに保存します。閲覧中のサイトや、そのサイトで動く拡張機能のスクリプトからは読み取れず、拡張機能のバックグラウンド処理だけが使用します。暗号化はしていません。
- 1 日ごとの件数（非表示にした件数、翻訳した件数）と推定費用。
- 判定の訂正（スパムではないと指定する操作や、返信を非表示にする操作）と、マークしたスパム。コメント本文を最大 300 文字保存し、訂正は直近の 3,000 件、マークした返信は直近の 500 件を保持します。
- TypeSafe の判定結果のキャッシュ（識別用のフィンガープリントとスコアのみで、本文は含まず、判定から 7 日後に削除）と、翻訳のキャッシュ（訳文を保存し、30 日間使われなければ削除）。初期設定では各キャッシュの上限は 50 MB で、上限に達すると古いものから削除します。

X と YouTube では、小さなスクリプト（`pagedata.js` と `ytdata.js`）がページ内で動き、そのページがすでに受信したサイトの API 応答を読み取ります。投稿の原文（翻訳前の文章）や、コメントの投稿者を確認するためです。読み取るだけで、リクエストを送ったり、サイトが受信する内容を変更したりすることはありません。

## 利用者が選べること

- ポップアップや設定から、サイトごとに ClearFlow をオフにしたり、整理と翻訳を別々にオフにしたりできます。
- 設定のデータとプライバシーの項目から、設定・統計・判定の訂正・マークしたスパムをエクスポートできます。キャッシュの消去や、訂正を含む統計と記録の消去もできます。マークしたスパムは設定の一覧から 1 件ずつ、またはまとめて削除できます。
- 拡張機能をアンインストールすると、保存した情報はすべて削除されます。
- TypeSafe と OpenRouter の API キーは、各サービスでいつでも無効化・再発行できます。

## 子どもの利用

ClearFlow は子どもを対象としたサービスではなく、利用者の情報を意図的に収集することはありません。
